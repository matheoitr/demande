Excellente idée : **Death Note est un terrain en or pour un oral de maths**, parce que toute l'enquête de L est littéralement du raisonnement probabiliste. Voici un sujet taillé pour le 20/20.

---

## 🎯 La problématique recommandée

> **« Dans quelle mesure les probabilités conditionnelles permettent-elles de raisonner efficacement dans l'incertain ? L'exemple de l'enquête de L contre Kira dans Death Note. »**

**Variantes si tu veux plus percutant :**
- « Peut-on démasquer un criminel insaisissable grâce aux mathématiques ? Le raisonnement bayésien de L dans *Death Note*. »
- « Comment le théorème de Bayes transforme-t-il des indices en certitudes ? »

**Pourquoi c'est un sujet 20/20** :
- Problématique ouverte
- Notions du programme : probabilités conditionnelles, Bayes, loi binomiale, exponentielle
- Problème réel (justice, médecine, IA)
- Exemples simples + calculs
- Originalité : un anime culte

## 🗂️ PLAN DÉTAILLÉ (≈ 10 minutes)

### 🎬 INTRODUCTION — ~1 min

Accroche :
« Un élève trouve un carnet surnaturel : il suffit d'y écrire un nom, en visualisant un visage, pour tuer à distance. Comment attraper un meurtrier qu'on ne voit jamais ? C'est le défi de L face à Kira dans *Death Note*. Et ce que L fait… c'est des mathématiques : du raisonnement probabiliste. »

Annonce du plan :
1. L’enquête = incertitude
2. Probabilité conditionnelle + Bayes
3. Limites + applications réelles

---

### I. Raisonner dans l'incertain — ~1 min 30

L ne voit pas Kira → seulement des indices partiels → réduire l’incertitude.

Règles du Death Note : nom + visage → mort en 40 secondes.

**Exemple : piège de Lind L. Tailor**
- Faux L diffusé uniquement dans le Kantō
- Kira le tue → il devait voir le visage → donc il est dans le Kantō

→ Probabilité conditionnelle : l’indice réduit l’espace des possibles.

---

### II. Probabilités conditionnelles et Bayes — ~4 min

#### A. Probabilité conditionnelle — ~1 min 15

Définition :
$$P_B(A) = \frac{P(A \cap B)}{P(B)}$$

Application :
- A = « Kira est dans le Kantō »
- B = « Kira tue le faux L »
→ B ne peut arriver que si A est vrai → probabilité ≈ 1

#### B. Théorème de Bayes — ~2 min

Formule :
$$P_E(H) = \frac{P_H(E)P(H)}{P(E)}$$

Exemple : « Light est-il Kira ? »

Étape 1 :
- P(H) = 0,05
- P_H(E) = 0,95
- P_¬H(E) = 0,10
→ P_E(H) ≈ 0,33

Étape 2 :
- P_H(E2) = 0,90
- P_¬H(E2) = 0,20
→ P_E2(H) ≈ 0,69

→ 5 % → 33 % → 69 % → convergence vers la certitude.

#### C. Loi binomiale — ~45 sec

Beaucoup de petits pièges indépendants :
$$P(\text{au moins 1}) = 1 - (1-p)^n$$

Exemple : p = 0,10, n = 30 → P ≈ 0,96

---

### III. Limites et ouverture — ~2 min 15

#### A. Limites
1. Prior subjectif
2. Données manipulables (Light crée de faux indices)
3. Corrélation ≠ causalité

#### B. Applications réelles
- Médecine : faux positifs
- Justice : ADN
- IA : filtres anti-spam

Critique : biais du procureur (confusion entre P(E|innocent) et P(innocent|E)).

---

## 🏁 CONCLUSION — ~30 sec

« Les probabilités conditionnelles permettent de raisonner dans l’incertain et de faire converger vers la vérité. Mais *Death Note* montre aussi que ces outils ne valent que si les données sont fiables. Les maths exigent de la rigueur. »

## 🧠 Questions probables du jury

1. Pourquoi le prior pose problème ?  
→ Parce qu’il influence tout le calcul.

2. Différence entre P_H(E) et P_E(H) ?  
→ Le premier est facile à estimer, le second est ce qu’on cherche.

3. Pourquoi une loi binomiale ?  
→ Répétition d’épreuves indépendantes.

4. Philo ou maths ?  
→ Maths dans la démonstration, citoyen dans l’ouverture.
